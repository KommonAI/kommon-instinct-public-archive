❯ pnpm instinct --help
instinct  Open Instinct: a personal agent you text on iMessage, with its own computer.

Usage: instinct <command> [options]   (add --help to any command)

Set up
  init     Write config.json and, with INKBOX_ADMIN_API_KEY, provision the agent's iMessage identity.
           instinct init --name "Maria" --phone +14155550100 --email maria@example.com --handle maria-instinct
  connect  Print the router number and `connect @handle` text; save the QR to <dataDir>/connect-qr.png.
           instinct connect

Run
  dev     Run the agent server in this process. --tunnel opens an Inkbox tunnel so iMessage reaches it.
          instinct dev --port 8080 --tunnel
  chat    Send one message to a running agent, locally or through api.maritime.sh.
          instinct chat "what is on my calendar tomorrow"
  status  Show what a running server reports on GET /.
          instinct status

Deploy
  deploy  Create the Maritime agent (own microVM with a desktop) from a built image. Needs MARITIME_API_KEY.
          instinct deploy --image ghcr.io/maria/open-instinct-agent:latest

Payments
  payments  Link the owner's Stripe Link wallet to the agent (prints the authorize URL) and show what is connected.
            instinct payments connect

People and trust
  invite  Add a person to the trusted network and create an Inkbox A2A invitation for their agent.
          instinct invite "Sam Lee" --tier partner --email sam@example.com --handle sam-instinct
  trust   Change tiers and scoped grants. Tiers: partner, family, friend, contact, stranger.
          instinct trust grant sam-lee calendar.write,plans.commit --until 2026-10-12 --max-usd 150 --note "dinner this week"

Customize
  persona  Read or change <dataDir>/PERSONA.md: the agent's name, voice, texting style and limits.
           instinct persona set "You are Pip. Dry wit, short sentences, never emojis."
  prompt   Print the system prompt your own conversation would get right now, built from the data dir.
           instinct prompt --layers

Proactive
  schedules  Cron or one-shot prompts the agent runs for you, delivered over iMessage.
             instinct schedules add "0 8 * * 1-5" "Morning briefing: calendar, weather, top emails" --tz America/New_York

Global: --data-dir <dir> (default $INSTINCT_DATA_DIR or ./.instinct), --help, --version

Env: INSTINCT_DATA_DIR, INKBOX_ADMIN_API_KEY, MARITIME_API_KEY, ANTHROPIC_API_KEY, COMPOSIO_API_KEY, COMPOSIO_TOOLKITS, LINK_CLIENT_ID, EDITOR
Customize the agent (persona, instructions, skills, memory, tiers): docs/CUSTOMIZE.md
